# Groq Chat

Простой сайт для бесплатного общения с моделью через Groq API (llama-3.3-70b-versatile) —
статический фронтенд + Node.js/Express бэкенд, который проксирует запросы к Groq
и хранит ключ на сервере (не в браузере).

## Запуск локально

```bash
cd grok-chat
npm install
cp .env.example .env
# впишите в .env свой GROQ_API_KEY (console.groq.com/keys)
npm start
```

Откройте http://localhost:3000

## Код доступа

Если задать `ACCESS_CODE` в `.env`, сайт при открытии попросит ввести этот код —
это защищает от того, что кто-то посторонний найдёт публичный URL и начнёт тратить
ваш лимит API-запросов. Оставьте поле пустым, если код не нужен.

## Системный промт

`SYSTEM_PROMPT` в `.env` задаёт роль/тон модели — она подставляется сервером как
системное сообщение перед каждым запросом, фронтенд об этом не знает. Оставьте
пустым, чтобы модель отвечала без заданной роли.

## Деплой в интернет

Бэкенд обязателен — ключ нельзя класть в чистый HTML/JS, иначе любой откроет
"Просмотр кода страницы" и увидит его. Варианты бесплатного/дешёвого хостинга
для такого Node.js-сервера:

- **Render** (render.com) — Web Service, free tier
- **Railway** (railway.app)
- **Fly.io**

Общая схема для любого из них:
1. Запушьте папку `grok-chat` в отдельный git-репозиторий (или подпапку — зависит от хостинга).
2. Build command: `npm install`, Start command: `npm start`.
3. В настройках хостинга задайте переменные окружения `GROQ_API_KEY`, `GROQ_MODEL`,
   `ACCESS_CODE`, `SYSTEM_PROMPT` — так же, как в `.env`, но через панель хостинга, не через файл.
4. После деплоя хостинг даст вам публичный URL — это и есть ваш сайт.

## Структура

- `server.js` — Express-сервер: раздаёт `public/`, проксирует `/api/chat` к Groq, простой rate-limit по IP.
- `public/` — фронтенд: `index.html`, `style.css`, `app.js`.
